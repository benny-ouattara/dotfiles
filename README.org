* Overview
Personal dotfiles managed with [[https://www.gnu.org/software/stow/][GNU Stow]] and [[https://github.com/LnL7/nix-darwin][nix-darwin]]. System configuration is declarative via Nix flakes with Home Manager.

Hosts:
- *kite* — macOS (x86_64-darwin), primary workstation
- *onyx* — macOS, secondary

* System Architecture
#+begin_example
nix-darwin/
  flake.nix        Entry point
  kite.nix         System packages, services, macOS defaults
  home.nix         Home Manager: git, zsh, fzf, ssh, direnv, starship, zoxide
  brew.nix         Homebrew casks and formulae (GUI apps, emacs-plus)
  overlays/        Custom Nix overlays (scripts)
  scripts/         System scripts (mail sync, WM watchdog, GC, etc.)
#+end_example

* File Navigation
** fzf
Fuzzy finder powered by =fd=. Respects =.gitignore=, skips =.git=.
- File search: bat preview
- Dir search: eza tree preview
- History: exact match, no preview
- Preview scroll: Ctrl+d/u

** Broot
Tree-based fuzzy file explorer. Catppuccin Mocha, Nerd Font icons, git status.
- Enter opens file in emacsclient at matching line
- =:rm= moves to trash
- =:gtr= jumps to git root
- =Alt+g= toggles git status filter
- Ctrl+t opens terminal at current dir

** Ranger
Three-column file manager with image preview via Kitty.
- =ee= opens in emacsclient
- =dD= moves to trash
- =Ctrl+f= fzf fuzzy find
- =gd/gs/go/gc/gD/gm= quick navigation (Downloads, Sync, org, Code, dotfiles, mail)
- =mk/mf= mkdir/touch
- Git-aware, hidden files shown
